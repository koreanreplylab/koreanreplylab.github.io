Application information

A local workflow for a Korean learning channel.

Korean Reply Automation is a privately operated Windows desktop project supporting Korean-language listening and response-practice content.

Current status: in development. The current connection-check program signs in with Google and reads the operator’s YouTube channel name and ID. Video-upload and scheduling automation are being developed; they are not yet a finished public service.

Purpose and operator control

The project is designed to help its operator prepare and upload selected learning videos to a YouTube channel the operator controls. It is currently for the operator’s own accounts, not a public sign-up service.

The operator decides which content, title, description, visibility, and schedule may be sent to YouTube. A connection check alone does not upload, publish, edit, or delete a video.

Why Google access is requested

  • View the YouTube account: confirm that Google authorization is connected to the intended channel by retrieving its channel name and ID.
  • Upload YouTube videos: prepare for an upload workflow authorized by the channel owner. This permission is requested in advance, although the current connection test does not use it to upload a video.

Where the application runs

The program runs on the operator’s Windows computer and uses Google OAuth and YouTube API Services. This website only provides application information and policy documents. It does not ask visitors to sign in or upload credentials.
