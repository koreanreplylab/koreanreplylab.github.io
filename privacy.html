Privacy Policy

Your channel access stays under your control.

Effective date and last updated: October 16, 2026

This policy describes the current Korean Reply Automation desktop project and this informational website. The operator and contact is Korean Reply Lab, koreanreplylan@gmail.com. The desktop project uses YouTube API Services.

1. Information accessed and its purpose

  • OAuth access and refresh tokens: authorize API requests and renew access without asking the operator to sign in for each request. The app does not collect a Google password.
  • YouTube channel name and ID: confirm the channel associated with authorization. The connection test displays these details in the local terminal.
  • Video files and metadata: the intended upload workflow will send operator-selected videos, titles, descriptions, visibility settings, and any selected publication schedule to YouTube. That upload workflow is still under development.

The configured authorization scopes are youtube.readonly and youtube.upload. The connection test retrieves channel name and ID only; it does not query a channel’s private video library or analytics.

2. Local storage and retention

The current connection program saves OAuth credentials in youtube_token.json in the operator’s local project folder. It displays channel details without maintaining a separate channel-data database. Tokens are kept only while this authorized connection is needed, and are removed when the operator disconnects or stops using the app.

Local project files and any backups are controlled by the operator. Access to that computer and those files must be protected. Tokens and client-configuration files must not be committed to this website’s public repository.

3. Sharing and AI services

Google receives authorization and API requests. A future upload sends the selected video and metadata to YouTube, where visibility is controlled by the selected YouTube settings. The current app does not sell Google user data, use it for advertising, or use it to train generalized AI models.

The current connection-check program sends no OAuth tokens, private channel information, or Google account data to external AI-generation providers. Content-generation services have not yet been selected. Any future integration that changes Google-data handling must be documented here before use.

The project’s handling of data obtained through Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

4. Disconnecting and deleting data

  1. Stop the local automation program.
  2. Remove Korean Reply Automation’s access in Google account security settings.
  3. Delete the local youtube_token.json file and any copies of tokens or retained YouTube API data from project backups.

Revoking access blocks further authorized API access; it does not itself erase local files or remove videos already uploaded to YouTube. Manage uploaded videos separately in YouTube Studio.

Contact koreanreplylan@gmail.com to request deletion of any Google user data retained by the operator. The operator will delete such retained data within seven days of a valid request or known revocation, subject to any applicable legal retention obligation. This is a manual operator process; the current desktop program does not automatically monitor revocation notifications.

5. Website hosting and cookies

These static pages add no application cookies, advertising, or analytics scripts, and do not receive the desktop app’s OAuth tokens. GitHub Pages hosts the website and may process ordinary hosting request data under the GitHub Privacy Statement.

6. Google services and policy changes

Google and YouTube process data under the Google Privacy Policy and applicable service terms. This policy will be updated when the application’s actual data practices change; the date above identifies the current version.
